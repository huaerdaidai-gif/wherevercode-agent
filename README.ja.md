## WhereverCode Agent とは？

AI との会話、プロジェクトファイル、タスク実行、複数エージェントによる共同作業を、シンプルなモバイルワークスペースに統合することを目指しています。エージェントの役割を特定の製品に固定しません。本リポジトリ **`wherevercode-agent`** は独立したアプリであり、旧 `wherevercode` オーケストレーション基盤とは別のプロジェクトです。

## 4 つの主要メニュー

| メニュー | 目指す体験 |
| --- | --- |
| **チャット** | 自然言語で会話・タスク実行。会話ごとにエージェントとモデルを選択し、初期値はユーザー設定のメインエージェント／モデル |
| **プロジェクト** | 許可されたプロジェクトソース、ファイル、タスク、承認、成果物の管理 |
| **チャンネル** | 許可されたチャンネルでメッセージ、ファイル、タスクを共有。DM はサーバー側の権限検証が必要 |
| **コントロール** | デバイス、エージェント、モデル、接続先、実行状況、監査記録の管理 |

### 設計方針

- **マルチエージェント／マルチモデル：** 固定的な役割ではなく、能力とタスクに応じて選択。
- **マルチデバイス：** ローカル端末、LAN 内 PC、許可されたリモートホストや VPS への接続を目指します。
- **複数のプロジェクトソース：** ローカルファイル、GitHub、リモート端末、対応クラウドストレージ。
- **人による管理：** 承認、一時停止、停止、目標変更、実行履歴。
- **権限と安全性：** 接続、ファイル操作、ツール実行にはユーザーの許可が必要。未実装機能を完成済みと表示しません。

これらは**製品の目標**であり、すべて実装済みという意味ではありません。

## ビルド・インストール

未確認のダウンロードリンクは掲載しません。実際のリリース情報と各プラットフォームの手順を確認してください。Android のデバッグ署名 APK は正式版ではなく、署名が異なる既存アプリを上書きできない場合があります。

Android には互換性のある Gradle 環境が必要です。完全な Gradle Wrapper が含まれない場合があります。iOS の配布には Apple の適切なビルド・署名手順が必要です。
