# V5 派工发布与回滚

发布对象是 WhereverCode Agent 的独立 MCP 服务。Android 前台服务从应用私有状态目录启动，监听回环端口 18744。频道连接与派工入口独立。连接器出现 `session terminated` 时重新初始化正式 MCP 会话。遇到 `channel_not_found` 时检查频道注册及授权，派工仍通过任务工具完成。

## 发布前

1. 记录 PR #3 的提交、CI 和独立复审结论。保留当前应用、Hand 包及任务数据库与私有状态的备份。在隔离环境演练恢复。升级后对旧版设备重新授予项目目录，旧授权缺少设备归属，无法自动迁移。
2. 在隔离环境验证 HTTPS 入口和 ChatGPT 连接器的认证兼容性，确认连接器指向独立服务。为 ChatGPT 签发仅含指定项目的派工凭证，为 Mac Codex 签发同项目的执行凭证。验证匿名、异项目及省略项目的请求被拒绝。访问日志省略 Authorization 和请求体。
3. 使用实际连接器确认派工身份可发现 `create_task`、`assign_task`、`get_task_status`，执行身份可发现 `list_my_tasks`、`claim_task`、`report_progress`、`submit_result`。完整演练成功后，由所有者批准生产发布。

## 受控验收

只向验收项目和指定执行方开放。ChatGPT 创建、指派及查询，Mac Codex 认领、执行、汇报及提交。分别演练暂停并恢复、停止、执行方掉线、租约过期及 Hand 产物重取。核对终态、真实进程和文件摘要。留存脱敏的任务 ID、轮次、控制回执、产物摘要及 CI 链接。

## 回滚

暂停新建和指派，停止验收任务并确认真实进程退出。撤销测试凭证，撤下 HTTPS 转发并停用 MCP 派工。保留升级后的数据库、审计及产物用于复盘。按演练结果恢复上版 Android 和 Hand。应用数据库版本不兼容时，从对应版本的备份恢复到隔离目录，保全升级后的任务记录，确认兼容后再切回。复核旧版健康和正式派工入口状态。
