## 本批直接实现

1. P0 安全：系统 CA + pin、路径/符号链接、停止/暂停/审批后复查、MCP 密钥封存与脱敏、频道发送者验证、终态写守卫，并验证锁透传。保留暂停/停止/恢复/改目标的既有持久化语义。
2. `search`：本地会话标题及正文、任务、项目、70 路由统一检索；结果打开对应真实会话/任务/项目/路由。支持加载、空结果、错误，不调用不存在的搜索 API。
3. `memory`：替换生产中的内存实现为同一接口的本机持久化实现，UI 与 BrainEngine 使用同一个实例；只有显式确认能保存事实，拒绝敏感内容，删除需确认。
4. `skills`：读取既有 Room SkillStore；项目筛选、真实详情、确认创建/删除及重启恢复。不会把技能记录当成已执行自动化。
5. 回归首批详情状态滞后、控制台遮挡；对话/模型/停止、任务控制、项目编辑/Diff、Agent 指派、频道消息转任务沿用现有控制器和测试，未实测部分保持未验证。
