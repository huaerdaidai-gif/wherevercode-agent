# 第二阶段剩余缺口与风险

本批增加三个本地功能的实际操作，仍不能声称 70 屏全量闭环。36 个路由有局部可调用能力，34 个仍只有明确缺口页；原有 33 个入口的完整业务范围仍需逐项验收。逐行范围以 acceptance-70.csv 为准。

## 需要后端/执行服务确认的契约信息

以下是缺失的数据和操作要求，**不是已经存在的接口，也不分配新的 HTTP 路径**；本批不改共享 API：

| 路由范围 | 缺失的请求 / 响应与权限要求 | 阻塞 |
|---|---|---|
| automation/automaker/triggers/templates/autoloop | 规则 ID/版本/项目/触发条件/动作/预算/幂等键；创建/修改/启停的版本冲突与受理回执；触发历史、执行任务 ID；服务端项目写权限及持久唤醒 | 现有 TaskScheduler 不存规则或耐久触发账本 |
| sync/handoff/recovery | 增量游标、变更版本、冲突策略、出站消息 ID/幂等键；同步/重试/取消回执；接力任务的执行所有权与租约转移；设备身份权限 | 没有完整跨端同步或事务性离线队列；不能用 DELIVERED 推断执行 |
| usage | 项目/模型/时间区间维度，真实 token/资源计量、价格来源/生效期、账单单位、额度、分页与缺失值 | 没有统一成本账本，不填估算数 |
| skillsmarket/skillbuilder/extensions 安装 | 目录版本、发布者签名、包摘要、依赖和权限清单；安装/卸载事务状态及审计；技能生成来源任务/审查证据 | 技能记录库与扩展声明不是可信安装或生成服务 |
| preview/browser/testmatrix/research | 运行实例 ID、设备/工作区/执行授权、生命周期与停止回执；隔离网络/端口、日志游标、测试项结果与产物摘要 | Shell 工具不提供隔离的产品级运行实例协议 |
| orchestrator/agentcompare | 可版本化图结构、节点依赖/预算/并发校验、运行 ID、各 Agent 真实输入输出及取消/审查状态 | 已有任务流水线可复用，尚缺完整图编辑/对比产品契约 |

统一要求：Loading/Empty/Error/Offline、鉴权失败与版本冲突可区分；离线不能改任务终态；停止、独立业务取消与暂停不能互换。现有 ControlCommandPort 的 STOP 到 cancelled 保持原义，未增加伪取消按钮。

## 本地/设备项与本批限制

- 搜索只有本机存储与路由元数据，不含云端、文件正文和实时远端索引；会话/任务/项目按真实 ID 打开，项目浏览仍走原授权检查。
- 记忆在当前设备应用沙盒持久化；不做跨端同步。损坏数据报错并保留原数据，尚无修复向导。旧进程内存记忆无法追溯迁移。删除设备备注不撤销配对授权。
- 技能复用既有 Room SkillStore；数据库初始化若回退内存，界面明确提示重启不保留。人工记录没有执行证据，不自动提升成功次数。自动生成、市场、持久规则服务仍缺失。
- 本地语音、Git/终端独立产品页、上下文/角色编辑、网络诊断/运行时探针等可继续分批实现；外部 Agent 接力/对比需要实际连接与权限，不能用静态状态验收。
- 环境未配置真实模型、平台账号与外部设备；流式推理成功、外部派单/审查/返工/集成全链路仍未做设备验收。未配置模型失败是失败证据。
- 本批原生测试覆盖导航与指定本地操作；不将 JVM 安全用例等同于真实设备网络/TLS/权限验收。任务暂停/恢复/停止的原生确认回执尚未全覆盖；审批后暂停检查及锁事务已有 JVM 回归。
- 360dp 控制台层级筛选仍可能换行；本批保留现有置顶与详情刷新修复，不重做 UI。原始首页 PNG/JPEG 缺失，不能承诺像素级对比。

PR #13 独立保留为未合并候选。本分支已逐提交移植 Android 改动并额外修复事务锁和审批后暂停检查，不代表其分支或 main 被合并。
